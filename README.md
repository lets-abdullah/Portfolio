# 🌐 Muhammad Abdullah — Full-Stack MERN Portfolio

Personal portfolio showcasing production web applications, enterprise POS/ERP systems, and engineering achievements.

## ✨ Features

- **Single-Page Architecture**: High-speed, smooth-scrolling single page with interactive section spy.
- **Executive Slate Design**: Custom slate & warm ochre gold palette with responsive viewport density.
- **Production Systems Showcase**: Live demos and GitHub source repositories for MERN applications.
- **Interactive AI Assistant**: Embedded portfolio assistant widget with contextual quick prompts.
- **Direct Contact System**: One-click clipboard email copy and interactive contact form.

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, CSS3
- **Animations & Visuals**: Aurora ambient shaders, StarBorder, ShinyText, BlurText, MagicRings
- **Backend & APIs**: Node.js, Express.js, MongoDB Atlas, RESTful APIs, JWT Auth
- **Icons**: Lucide React

## 🚀 Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/lets-abdullah/Portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
